# Safe Logins Module

This module focuses on securing login processes for specific social media platforms.
It provides platform-specific checklists and tools to audit login security settings.

## Contents
- `guidelines/` – Platform-specific login security checklists.
- `tools/` – Scripts to help audit exported account data for login settings.

## Usage
1. Check the guideline for your platform in `guidelines/`.
2. If you have exported your account data (from the platform's settings), use the tools to scan for security misconfigurations.
