# Facebook Login Security Checklist

## Password
- [ ] Use a strong, unique password (>=16 characters) generated by a password manager.
- [ ] Never reuse this password on any other site.
- [ ] Consider using a passphrase of 4+ random words.

## Two-Factor Authentication (2FA)
- [ ] Enable 2FA using an authenticator app (e.g., Google Authenticator, Authy) or hardware security key (YubiKey).
- [ ] Avoid SMS-based 2FA due to SIM-swapping risks.
- [ ] Save backup codes in a secure location (e.g., encrypted password manager).

## Login Alerts
- [ ] Enable login alerts for unrecognized devices or locations.
- [ ] Review active sessions regularly and log out unused devices.

## Account Recovery
- [ ] Ensure recovery email and phone number are up-to-date and secured with 2FA.
- [ ] Do not use shared or easily accessible recovery emails.

## Third-Party App Access
- [ ] Review and revoke unused third-party app connections.
- [ ] Remove any apps that have excessive permissions (e.g., posting on your behalf, accessing messages).

## Additional Tips
- [ ] Use a dedicated email address for social media accounts (not your primary personal/work email).
- [ ] Consider using a username that does not reveal your real name.
- [ ] Be cautious of phishing attempts; always verify the URL before entering credentials.
- [ ] Use a password manager to detect phishing sites (it won't auto-fill on fake sites).

## If You Suspect a Compromise
1. Immediately change your password.
2. Check active sessions and log out all unfamiliar devices.
3. Verify 2FA is still enabled.
4. Review recent account activity for unauthorized actions.
5. Consider reporting to the platform's support team.
