# Usage Analytics Module

This module analyzes login/logout or online status data to compute usage statistics and detect anomalies that may indicate account compromise.

## Contents
- `guidelines/` – Guidance on collecting login data from social media platforms.
- `tools/` – Scripts to analyze login events and generate reports.

## Usage
1. Export your login/logout or active sessions data from the platform (if available).
2. Use the tools in `tools/` to compute average usage time, daily patterns, and flag anomalies.
