🛡️ Overview

social-safe is a Python package (with Node.js wrapper) that helps you monitor and protect your Instagram account by detecting suspicious follower/following changes, auditing new followers for risky characteristics, and alerting you via email when actionable changes are detected.

Unlike native Instagram controls, social-safe provides active monitoring and auditing capabilities that work continuously to keep you informed about your account's safety.

✨ Key Features

🔍

Follower/Following Monitoring

Detects new followers, lost followers, new follows, and unfollows since last check with customizable thresholds.

🛡️

Privacy Setting Alerts

Gets notified if your account accidentally switches from private to public (or vice versa).

🕵️‍♂️

Privacy Audit

Scans new followers for risky characteristics: zero posts, zero followers, high following/follower ratio.

📧

Email Alerts

Sends detailed email alerts when thresholds are exceeded or risks are detected.

⚙️

Highly Customizable

Configure everything via environment variables: thresholds, monitored items, audit checks, etc.

🔐

Secure by Design

Never stores passwords; uses environment variables and app-specific passwords only.

📦 Installation

From GitHub (Recommended)

pip install git+https://github.com/PyMite6941/social-safe.git

Or for development:

git clone https://github.com/PyMite6941/social-safe.git
cd social-safe
pip install -e .

Node.js Wrapper (Optional)

Provides a socialsafe command that wraps the Python package.

npm install -g socialsafe-wrapper

Requires the Python package to be installed first.

▶️ Usage

Set environment variables (copy .env.example to .env and fill):

export IG_USERNAME="your_instagram_handle"
export IG_PASSWORD="your_app_specific_password"
export ALERT_EMAIL="your_alert@example.com"
export ALERT_APP_PASSWORD="your_smtp_app_password"

⚙️ How It Works

1

Authenticate

Securely logs into Instagram using your credentials via Instaloader (read-only access).

2

Fetch Data

Retrieves your current follower and following lists.

3

Compare & Analyze

Compares against previous run, checks privacy setting, and optionally audits new followers for risks.

4

Alert if Needed

Sends email alerts when thresholds are exceeded, privacy changes, or risky followers detected.

5

Update State

Updates the state file for efficient comparison in the next run.

❓ Frequently Asked Questions

Is my Instagram password safe?

Yes. Your password is only used to authenticate with Instagram via Instaloader and is never stored, logged, or transmitted elsewhere. We recommend using an app-specific password from Instagram's security settings.

Can this tool post or modify my account?

No. social-safe is read-only. It only fetches your follower/following lists and account information. It does not post, message, follow, unfollow, or modify your account in any way.

What if I have many followers?

The tool is efficient and only processes changes since the last run. Even accounts with hundreds of thousands of followers typically complete checks in seconds.

How often should I run it?

For most users, running it once per hour via cron is sufficient. You can adjust frequency based on your needs.

Does it work with business or creator accounts?

Yes. The tool works with any Instagram account type (personal, business, creator) as long as you have the login credentials.
