🛡️ Overview

social-safe is a comprehensive privacy protection suite that monitors multiple social media platforms (Instagram, Twitter/X, LinkedIn, and more) to detect suspicious changes, audit account security, scan for threats in posts/DMs, and alert you via email when actionable changes are detected.

Unlike native platform controls, social-safe provides active monitoring, OSINT capabilities, and automated auditing that works continuously to keep you informed about your accounts' safety.

🌐 Supported Platforms

social-safe supports monitoring and auditing for major social media platforms with platform-specific adapters:

📷

Instagram

Follower/following monitoring, privacy setting alerts, new follower risk assessment, post/DM content scanning

🐦

Twitter/X

Follower/following monitoring, privacy setting alerts, new follower risk assessment, tweet/DM content scanning

💼

LinkedIn

Connection monitoring, privacy setting alerts, new connection risk assessment, post/message content scanning

🔧

Extensible

Easy to add new platforms using the base adapter class - Facebook, TikTok, Reddit, etc.

✨ Key Features

👥

Follower/Connection Monitoring

Detects new connections, lost connections, and changes since last check with customizable thresholds for each platform.

🔒

Privacy Setting Alerts

Gets notified if your account privacy settings change unexpectedly (private ↔ public, protected ↔ unprotected).

🕵️‍♂️

Privacy & Risk Audit

Scans new connections for risky characteristics: zero posts, zero followers, high following/follower ratio, and more.

📧

Email Alerts

Sends detailed email alerts when thresholds are exceeded, risks are detected, or security issues are found.

🔍

OSINT & Threat Detection

Scans posts and DMs for suspicious content (malicious links, known threat patterns) and PII (personal information leaks).

⚙️

Highly Customizable

Configure everything via environment variables: thresholds, monitored items, audit checks, OSINT patterns, etc.

🔐

Secure by Design

Never stores passwords; uses environment variables and platform-specific app passwords only.

🔄

Multi-Platform

Monitor multiple social media accounts from a single interface with platform-specific configuration.

🔐 Security Audit Features

First-Line Defense: Encryption & Security Auditing

As requested, the first section of the audit focuses on verifying that applications are properly securing your data:

  • Checks for end-to-end encryption in direct messages where available
  • Verifies that platforms are using secure connections (HTTPS/TLS)
  • Monitors for known security vulnerabilities in platform implementations
  • Checks for proper implementation of security features like two-factor authentication
🔐

Encryption Audit

Verifies that applications are using proper encryption for data in transit and at rest where possible.

🕵️‍♂️

PII Scanning in Posts/DMs

Scans your posts and direct messages for personally identifiable information (PII) that could compromise your privacy:

  • Email addresses, phone numbers, physical addresses
  • Social Security Numbers, ID numbers
  • Financial information (credit cards, bank accounts)
  • Dates of birth, passport numbers
🧪

OSINT Threat Detection

Scans content for known threats and suspicious patterns:

  • Malicious links and phishing attempts
  • Known threat patterns (like the "Mr. Beast image" hacks mentioned)
  • Suspicious text patterns indicating scams or social engineering
  • Known malicious image hashes
  • Phishing attempts (malicious links, suspicious URLs)
  • AI-evaluated social engineering risk in text content

📦 Installation

From GitHub (Recommended)

pip install git+https://github.com/PyMite6941/social-safe.git

Or for development:

git clone https://github.com/PyMite6941/social-safe.git
cd social-safe
pip install -e .

Node.js Wrapper (Optional)

Provides a socialsafe command that wraps the Python package.

npm install -g socialsafe-wrapper

Requires the Python package to be installed first.

▶️ Usage

Set environment variables (copy .env.example to .env and fill):

# Instagram (required for Instagram monitoring)
export IG_USERNAME="your_instagram_handle"
export IG_PASSWORD="your_app_specific_password"

# Twitter/X (optional)
export TWITTER_USERNAME="your_twitter_handle"
export TWITTER_BEARER_TOKEN="your_twitter_bearer_token"
# OR
export TWITTER_API_KEY="your_api_key"
export TWITTER_API_SECRET="your_api_secret"
export TWITTER_ACCESS_TOKEN="your_access_token"
export TWITTER_ACCESS_TOKEN_SECRET="your_access_token_secret"

# LinkedIn (optional - future implementation)
# export LINKEDIN_USERNAME="your_linkedin_handle"
# export LINKEDIN_ACCESS_TOKEN="your_access_token"

# Alert configuration (required)
export ALERT_EMAIL="your_alert@example.com"
export ALERT_APP_PASSWORD="your_smtp_app_password"
export SMTP_SERVER="smtp.gmail.com"
export SMTP_PORT="465"

# Monitoring configuration
export MONITOR_FOLLOWERS="true"
export MONITOR_FOLLOWING="true"
export ALERT_THRESHOLD_NEW_FOLLOWERS="10"
export ALERT_THRESHOLD_LOST_FOLLOWERS="10"
export EXPECTED_PRIVACY="private"

# Audit configuration
export AUDIT_ENABLED="true"
export AUDIT_RISK_ZERO_POSTS="true"
export AUDIT_RISK_ZERO_FOLLOWERS="true"
export AUDIT_RISK_HIGH_FOLLOWING_RATIO="true"
export AUDIT_FOLLOWING_RATIO_THRESHOLD="100"
export AUDIT_MIN_FOLLOWERS_FOR_RATIO="10"
export AUDIT_ALERT_THRESHOLD_RISKY="5"

# OSINT & PII scanning (optional)
export ENABLE_CONTENT_SCANNING="false"
export ENABLE_PII_DETECTION="false"
# Add custom keywords for content scanning (comma-separated):
# CONTENT_SCAN_KEYWORDS="free nft,click here for,urgent action required,mr beast,crypto giveaway"
# Add custom PII patterns (regex format):
# PII_PATTERNS="\\\\b\\\\d{3}-?\\\\d{2}-?\\\\d{4}\\\\b, \\\\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\\\\.[A-Z|a-z]{2,}\\\\b"

Then run the monitor:

# Monitor all configured platforms
socialsafe-monitor

Or via the npm wrapper (if installed):

socialsafe

Or monitor a specific platform:

# Monitor only Instagram
socialsafe-monitor --platform instagram

# Monitor only Twitter/X
socialsafe-monitor --platform twitter

⚙️ How It Works

1

Authenticate

Securely logs into each configured social media platform using your credentials via platform-specific libraries or official APIs (read-only access).

2

Fetch Data

Retrieves your current follower/following lists, connection data, and optionally recent posts/messages for each platform.

3

Compare & Analyze

Compares against previous run, checks privacy settings, performs risk audits on new connections, and scans content for threats and PII if enabled.

4

Alert if Needed

Sends email alerts when thresholds are exceeded, privacy changes are detected, risky connections are found, or security/threat issues are identified.

5

Update State

Updates the state file for each platform for efficient comparison in the next run.

❓ Frequently Asked Questions

Is my social media password safe?

Yes. Your passwords are only used to authenticate with each platform via their official APIs or libraries and are never stored, logged, or transmitted elsewhere. We recommend using app-specific passwords or app-only authentication where available.

Can this tool post or modify my accounts?

No. social-safe is read-only. It only fetches your data and does not post, message, follow, unfollow, or modify your accounts in any way.

What platforms are currently supported?

Currently supported platforms include Instagram and Twitter/X, with LinkedIn and other platforms planned for future releases. The framework is designed to be easily extensible to new platforms.

How does the OSINT scanning work?

The OSINT scanning feature (when enabled) analyzes your posts and direct messages for known threat patterns, malicious content, and personally identifiable information. It only scans YOUR own content that you have permission to analyze.

How often should I run the monitor?

For most users, running it once per hour via cron is sufficient. You can adjust frequency based on your needs and platform API rate limits.

Does it work with business or creator accounts?

Yes. The tool works with any account type (personal, business, creator) on supported platforms as long as you have the login credentials.

Is this tool compliant with platform terms of service?

Yes. social-safe only uses official APIs and granted permissions to access your own account data, which is compliant with platform terms of service.
