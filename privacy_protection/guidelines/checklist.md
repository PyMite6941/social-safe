# Privacy & Data Hygiene Checklist

## Account Security
- [ ] Enable strong, unique passwords (use a password manager).
- [ ] Enable two‑factor authentication (prefer authenticator app or hardware key).
- [ ] Review active sessions and log out unused devices.
- [ ] Update recovery email/phone and secure them with 2FA.

## Data Minimization
- [ ] Remove unnecessary profile fields (phone, address, birthday).
- [ ] Disable geotagging and location sharing in posts.
- [ ] Strip EXIF metadata from photos before upload.
- [ ] Limit third‑party app connections; revoke unused tokens.
- [ ] Set audience to “Friends Only” or “Private” where possible.
- [ ] Avoid sharing sensitive personal details in public posts.

## Data Handling & Storage
- [ ] Encrypt sensitive files at rest (use AES‑256 via platform tools or VeraCrypt).
- [ ] Use end‑to‑end encrypted messaging for private chats (Signal, WhatsApp with encrypted backups off).
- [ ] Store backups offline or in encrypted cloud storage.
- [ ] Apply retention schedules: delete or anonymize old exports, logs, and backups.
- [ ] Before sharing data, redact PII (emails, phone numbers, IDs) unless required.

## Browser & Device Hygiene
- [ ] Use a privacy‑focused browser (Brave, Firefox with hardened settings).
- [ ] Block trackers with uBlock Origin or similar.
- [ ] Clear cookies and cache regularly, or use container tabs.
- [ ] Keep OS, apps, and browser up to date.
- [ ] Use a VPN on public Wi‑Fi; prefer cellular or trusted hotspot otherwise.
- [ ] Disable unnecessary app permissions (mic, camera, contacts, location).

## Monitoring & Incident Response
- [ ] Set up alerts for new logins or password changes.
- [ ] Review account activity logs monthly.
- [ ] Have a breach response plan: revoke tokens, reset passwords, notify affected parties.
- [ ] Periodically test data deletion and recovery procedures.

## Social‑Media Specific
- [ ] Audit connected apps and third‑party permissions quarterly.
- [ ] Disable personalized ads and ad tracking where offered.
- [ ] Turn off read receipts and online status if platform allows.
- [ ] Use disappearing messages for sensitive conversations.
- [ ] Avoid clicking unknown links; verify URLs before opening.
